# Certificate of Conformity Generator

A web application for generating professional Certificates of Conformity for vehicle transactions.

## Features

- 📁 CSV file upload for batch processing
- ✍️ Manual data entry for single certificates
- 📄 DOCX format export
- 🖨️ Print-ready certificates
- 🎨 Professional template design
